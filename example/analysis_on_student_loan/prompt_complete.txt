**你的任务**：对学生贷款数据进行完整的数据分析。数据包含 **CSV/Excel 文件** 和 **SQLite 数据库**。

**重要**：系统已完成第 1 轮 bootstrap，你现在必须立即开始第 2 轮分析，不要等待用户指令。

## 数据背景

这是一个关于学生贷款的数据集，包含学生的人口统计信息、教育记录、财务状况和就业状态等信息。

## 数据文件清单

**重要说明**：
- 每个数据集都有 **CSV 和 XLSX 两个版本**，内容相同，可任选其一
- SQLite 数据库包含所有数据，表名与文件名对应（如 `enrolled` 表 = `enrolled.csv`）

**10 个数据集**（每个都有 `.csv` 和 `.xlsx` 两个文件）：
1. `bool` - 布尔标记（仅包含 name 列，3 条记录）
2. `person` - 学生名单（仅包含 name 列，1000 名学生）
3. `disabled` - 残疾学生（name 列）
4. `enlist` - 入伍记录（name, organ 列）
5. `filed_for_bankrupcy` - 破产记录（name 列）
6. `longest_absense_from_school` - 最长缺勤记录（name, month 列）
7. `male` - 男性学生（name 列，存在即为男性）
8. `no_payment_due` - 还款记录（name, bool 列）
9. `unemployed` - 失业学生（name 列）
10. `enrolled` - 入学记录（name, school, month 列，最大文件）

**SQLite 数据库**：
- `student_loan.sqlite` (300KB) - 包含上述 10 个表，表名与文件名一致

**数据关系**：
- 所有表通过 `name` 字段关联（学生姓名）
- `person` 表是主表，包含所有学生
- 其他表是子集，只包含特定条件的学生

**重要**：第一轮执行后，系统会显示所有表的完整字段列表。**必须严格使用第一轮结果中的字段名**，不要根据文件名推测字段。

**目的**：合并多个表，发现数据之间的关联。

**示例：分析失业学生的性别和还款情况**

```
<Analyze>
分析失业学生的性别和还款情况
</Analyze>

<Code>
import sqlite3
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from pathlib import Path

# 从第一轮输出中复制数据库路径
DB_PATH = r"/home/tdz/DeepAnalyze/demo/workspace/session_xxx/student_loan.sqlite"
OUTPUT_DIR = Path("generated")
OUTPUT_DIR.mkdir(parents=True, exist_ok=True)

# 合并 unemployed, male, no_payment_due 表
query = """
SELECT 
    u.name,
    CASE WHEN m.name IS NOT NULL THEN '男性' ELSE '女性' END AS gender,
    CASE WHEN n.name IS NOT NULL THEN '有还款' ELSE '无还款' END AS payment_status
FROM unemployed u
LEFT JOIN male m ON u.name = m.name
LEFT JOIN no_payment_due n ON u.name = n.name
"""

with sqlite3.connect(DB_PATH, timeout=30) as conn:
    conn.execute("PRAGMA busy_timeout = 30000;")
    df = pd.read_sql_query(query, conn)

# 统计
cross_tab = pd.crosstab(df['gender'], df['payment_status'])
cross_tab.to_csv(OUTPUT_DIR / "unemployed_gender_payment.csv", encoding='utf-8')

# 可视化
plt.figure(figsize=(8, 6))
cross_tab.plot(kind='bar', stacked=True)
plt.title("失业学生性别与还款情况")
plt.xlabel("性别")
plt.ylabel("人数")
plt.tight_layout()
plt.savefig(OUTPUT_DIR / "unemployed_gender_payment.png", dpi=120)
plt.close()

print(f"分析完成：失业学生 {len(df)} 人")
</Code>
```

import sqlite3
import pandas as pd
from pathlib import Path

DB_PATH = r"真实的数据库绝对路径"
OUTPUT_DIR = Path("generated")
OUTPUT_DIR.mkdir(parents=True, exist_ok=True)

# 使用 SQL JOIN 合并多个表
query = """
SELECT e.name, e.school, e.month, m.name AS is_male
FROM enrolled e
LEFT JOIN male m ON e.name = m.name
LIMIT 1000
"""

with sqlite3.connect(DB_PATH, timeout=30) as conn:
    conn.execute("PRAGMA busy_timeout = 30000;")
    merged = pd.read_sql_query(query, conn)

# 分析合并后的数据
