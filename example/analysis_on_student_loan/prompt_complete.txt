这是一个关于学生贷款的数据集，包含学生的人口统计信息、教育记录、财务状况和就业状态等信息。

## 数据文件清单

**重要说明**：
- 每个数据集都有 **CSV 和 XLSX 两个版本**，内容相同，可任选其一
- SQLite 数据库包含所有数据，表名与文件名对应（如 `enrolled` 表 = `enrolled.csv`）

**10 个数据集**（每个都有 `.csv` 和 `.xlsx` 两个文件）：
1. `bool` - 布尔标记（仅包含 name 列，3 条记录）
2. `person` - 学生名单（仅包含 name 列，1000 名学生）
3. `disabled` - 残疾学生（name 列）
4. `enlist` - 入伍记录（name, organ 列）
5. `filed_for_bankrupcy` - 破产记录（name 列）
6. `longest_absense_from_school` - 最长缺勤记录（name, month 列）
7. `male` - 男性学生（name 列，存在即为男性）
8. `no_payment_due` - 还款记录（name, bool 列）
9. `unemployed` - 失业学生（name 列）
10. `enrolled` - 入学记录（name, school, month 列，最大文件）

**SQLite 数据库**：
- `student_loan.sqlite` (300KB) - 包含上述 10 个表，表名与文件名一致

**数据关系**：
- 所有表通过 `name` 字段关联（学生姓名）
- `person` 表是主表，包含所有学生
- 其他表是子集，只包含特定条件的学生

### 5. 第 7 轮：SQLite 多表关联分析

**重要**：第 7 轮开始使用 SQLite 数据库，不再使用 CSV 文件。

**目的**：合并多个表，发现数据之间的关联。

**强制要求**：
- ✅ 使用第 1 轮 Bootstrap 提供的 SQLite 数据库绝对路径
- ✅ 使用 SQL JOIN 语句进行多表关联
- ✅ 严格使用第 1 轮显示的表名和字段名
- ✅ **每张表在 set_index/reindex 之前必须先 `drop_duplicates(subset=['name'])`**，确保唯一键再做 JOIN，避免 pandas duplicate labels 报错
- ✅ **合并结果中必须保留 `name` 列**（不要 `set_index('name')` 后又访问 `name`，若已设为索引请 `reset_index()`）
- ✅ `longest_absense_from_school.month` 需重命名为 `absense_month`（例如 `df.rename(columns={'month': 'absense_month'})`），`no_payment_due.bool` 需映射为 `payment_status`
- ❌ **禁止使用 "Join"、"Merged"、"Result" 等作为表名**
- ❌ **JOIN 只是 SQL 关键字,不是表名,不能写 FROM Join**
- ✅ **正确写法**: `FROM enrolled e LEFT JOIN disabled d ON e.name = d.name`

> **若 pandas 在生成 CSV/PNG 时提示 `"['name'] not in index"`，表示你把 name 设为了索引。请在写入前执行 `merged_df = merged_df.reset_index(drop=True)`，或直接避免 `set_index('name')`。**

import sqlite3
import pandas as pd
import matplotlib.pyplot as plt

from pathlib import Path

# 从第一轮输出中复制数据库路径
DB_PATH = r"/home/tdz/DeepAnalyze/demo/workspace/session_xxx/student_loan.sqlite"

# 合并 unemployed, male, no_payment_due 表
query = """
SELECT 
    u.name,
    CASE WHEN m.name IS NOT NULL THEN '男性' ELSE '女性' END AS gender,
    CASE WHEN n.name IS NOT NULL THEN '有还款' ELSE '无还款' END AS payment_status
FROM unemployed u
LEFT JOIN male m ON u.name = m.name
LEFT JOIN no_payment_due n ON u.name = n.name
"""

with sqlite3.connect(DB_PATH, timeout=30) as conn:
    conn.execute("PRAGMA busy_timeout = 30000;")
    df = pd.read_sql_query(query, conn)

**代码模板 C：合并多个表分析（仅第 7 轮使用，基于 SQLite）**

```python
import sqlite3
import pandas as pd
from pathlib import Path

DB_PATH = r"真实的数据库绝对路径"
OUTPUT_DIR = Path("generated")
OUTPUT_DIR.mkdir(parents=True, exist_ok=True)

# 读取并去重
with sqlite3.connect(DB_PATH, timeout=30) as conn:
    conn.execute("PRAGMA busy_timeout = 30000;")
    df_enrolled = pd.read_sql_query("SELECT name, school FROM enrolled", conn).drop_duplicates(subset=["name"])
    df_no_due = (
        pd.read_sql_query("SELECT name, bool FROM no_payment_due", conn)
        .drop_duplicates(subset=["name"])
        .rename(columns={"bool": "payment_status"})
    )
    df_absense = (
        pd.read_sql_query("SELECT name, month FROM longest_absense_from_school", conn)
        .drop_duplicates(subset=["name"])
        .rename(columns={"month": "absense_month"})
    )

# 合并并保留 name 列
merged = (
    df_enrolled
    .merge(df_no_due, on="name", how="left")
    .merge(df_absense, on="name", how="left")
)

# 保证 name 仍是列（不要 set_index），避免后续选择列时报错
merged.to_csv(OUTPUT_DIR / "multi_table_join_result.csv", index=False)
print(merged.head())
```

**注意**：`male` 表只有 `name` 字段，如果 name 存在则表示是男性，不存在则为女性。
